# Local Audit Area

`_audit/input/` is local-only and ignored by git. Put private Excel/PDF audit inputs there.

Generated files live under `_audit/output/`:

- `public_dashboard_audit.md`
- `public_summary_from_excel.json`
- `repo_tree_before.txt`
- `repo_tree_after.txt`

Do not commit private workbook exports or PDFs.
